## 1. 项目定位

元见不是单一网络安全产品，而是面向信息爆炸场景的信息检索与情报整理服务。核心目标是从公开信源中筛选值得关注的信息，覆盖 AI、时政、综合新闻和网络安全，并根据用户主题画像提供定制化结果。

网络安全是特色方向之一，不要把整个产品重新收敛成网络安全日报。网页、公开 API、Agent Markdown、RSS 和 MCP 读取同一套公开数据层。

## 3. 已完成能力

### 3.1 主题与画像

文件：`packages/contracts/src/trial-themes.ts`、`packages/contracts/src/trial-profile.ts`。

当前有 12 个试用主题，分为 AI 和网络安全两组：AI 大模型、AI Agent、AI 产品、算力基础设施、开源生态、AI 产业与政策；网络安全漏洞、威胁情报、勒索、厂商、安全政策、安全研究。主题会映射到公开 API 分类，网页和 MCP 不各自维护分类规则。

### 3.2 MCP 问卷初始化

无 Token 访问 `/api/mcp` 时，只开放 `yuanjian_start_topic_setup` 和 `yuanjian_confirm_topic_setup`。Agent 会引导用户选择关注方向、阅读目标、信息深度、阅读频率和细分主题。确认后系统在 PostgreSQL 中创建画像并签发一次性 Bearer Token。数据库保存 Token 摘要，不保存明文 Token。客户端需要重新连接并携带 `Authorization: Bearer <token>`。

### 3.3 多 Token 与日志

文件：`packages/backend/src/config.ts`、`apps/api/src/routes/mcp.ts`。

预配置格式为 `MCP_TOKENS=负责人:yuanjian_aaa:vulnerability|threat-intel;同事A:yuanjian_bbb:ai-products`。分号分隔调用者，竖线分隔主题。认证使用长度检查和 `timingSafeEqual`。错误 Token 返回 401 和 `WWW-Authenticate`。日志记录调用者标签、主题和分类，不记录明文 Token。

### 3.4 画像默认取数

文件：`packages/backend/src/mcp-profile.ts`、`packages/backend/src/mcp-personalization.ts`、`apps/api/src/routes/mcp.ts`。

优先级是：显式 `category`，其次 `scope=all`，其次当前 Token 画像，最后是无画像不过滤。`latest`、`search`、`hot` 支持画像上下文。画像筛选结果少于 3 条时，保留画像命中项并从全部公开动态补充，结构化结果标记 `relaxed=true`。

### 3.5 多分类公开读取

文件：`packages/backend/src/publication/items.ts`、`packages/backend/src/publication/v1.ts`、`apps/api/src/routes/v1.ts`、`apps/api/src/routes/agent.ts`。

底层查询已支持 `categories` 数组、多分类 SQL、缓存 Key 隔离、HTTP 单分类参数兼容转换和查询结果分类集合返回。

## 4. 目前未完成与需要复核

### 4.1 真实 Token 演示证据

自动化测试已覆盖静态 Token 认证、主题说明、工具列表和日志；Docker 实机本轮主要验证了无 Token 初始化。正式演示前应真实完成问卷、生成数据库 Token、重新连接、调用最新/搜索/热点/日报，并用第二个 Token 验证画像不串线，同时检查日志不出现明文 Token。

### 4.2 信源配置不等于抓取成功

`industry/sources.json` 只代表信源配置，不代表信源可访问、抓取成功、内容入库或进入精选。修改信源后必须检查抓取日志、数据库数量、最近抓取时间和失败原因。

### 4.3 敏感信源边界

只使用官方 RSS/Atom、官方 API、获得授权的第三方接口、合规低频公开解析或人工导入。不得绕过登录、验证码、付费墙、访问控制、robots 或反自动化措施。「威胁情报」板块（原「暗网情报」占位，2026-10-13 更名并改为**信源绑定**）现由「元见威胁情报」特色信源经企业微盘**人工投递**供给（`industry/sources.json` 的 `ext-threat-intel`；`industry/topics.json` 的 `threat-intelligence` 主题用 `sourceId` 只收该源、不混公开源）；仍**不做暗网实采、不绕过任何访问控制**。

### 4.4 画像排序仍是后续工作

当前画像影响分类过滤、默认时间窗口和默认条数；阅读目标暂未进入排序权重。排序权重属于 P1，必须先产品确认并补测试，不要直接改变现有排序公式。

### 4.5 网页与 MCP Token 互认

数据库模型已支持网页和 MCP 两种来源，但仍需实测网页生成 Token 能否直接用于 MCP、MCP 生成 Token 能否被网页识别，以及主题更新和 Token 轮换后的行为。
